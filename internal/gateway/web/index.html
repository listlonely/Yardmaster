全局代理
只需在此设置一次；添加服务商/账号时选择是否走它。留空=跟随系统；direct=显式直连；http(s)/socks5://…

保存后写入 settings.json；监听地址等装配期字段需重启 serve 完全生效，令牌变更即时生效。所有写路径经备份栈 + 审计。

标准 API 类内置开箱即用；仅订阅账号（Claude / Codex / Gemini 会员）由社区插件适配导入（主程序无厂商 OAuth 代码）
尚未配置服务商点击上方「＋ 添加服务商」，从厂商预设开始（或用 CLI yardmaster provider add）
意图分配意图由网关内置识别；每类任务配一条有序模型链，按策略自动分配

选型建议：编程 / 兜底 → 配 2~3 个模型的链（自动容灾）；问答 → 便宜快速的模型；长上下文 / 图片理解 → 具备对应能力的模型。改动即时热生效（写前备份 + 审计）。
